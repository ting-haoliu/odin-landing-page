# Odin Landing Page

This is a landing page project created as part of [The Odin Project](https://www.theodinproject.com/)'s curriculum. The primary goal of this project is to build a full landing page from a design mockup using HTML and CSS Flexbox.

## Features
- **Hero Section**: A dark-themed intro section featuring an interactive navigation bar, main titles, and an image placeholder.
- **Information Section**: A neatly structured area showcasing 4 dynamic, flexbox-powered cards with placeholder illustrations.
- **Quote Section**: A dedicated testimonial section with a custom light-grey background and italicized typography.
- **Call to Action**: A vibrant blue section designed with `flex: space-between` to correctly align the engaging sign-up prompt and its button.
- **Clean Codebase**: Fully semantic HTML structure paired with a comprehensive single CSS stylesheet.

## Built With
- HTML5
- CSS3 (Flexbox heavily utilized for all block-level alignment and structure)
- Fonts by Google Fonts (Roboto)
